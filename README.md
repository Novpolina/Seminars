# C Systems Programming Seminars

Учебные примеры по системному программированию в Linux на языке C.

- `seminar5` — файловые дескрипторы, чтение и запись файлов;
- `seminar6` — процессы и межпроцессное взаимодействие, включая System V shared memory.

Каждый файл содержит отдельный небольшой пример и компилируется независимо, например:

```bash
gcc seminar5/1.c -o example
./example
```
